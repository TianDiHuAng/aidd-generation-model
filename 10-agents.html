LLM 与智能体：把工具链串成对话

生成模型各自擅长一步——生成结构、预测性质、规划路线。把它们串成一整个工作流的"胶水层"，如今越来越多地由大语言模型充当：会读文献、会挑工具、会看结果、会改主意。

核心思想

大语言模型（LLM）在药物发现里扮演的不是"生成分子"的角色，而是通用接口与规划器：理解自然语言描述的任务，把它拆解成对专业工具的调用（性质预测器、逆合成规划器、对接服务、数据库检索），读取工具输出，再决定下一步。思维链提示让多步推理可靠一些；ReAct 把"推理"与"行动"交替进行，形成"思考—调用—观察—再思考"的循环；工具微调让模型学会"何时调用什么工具、传什么参数"。化学领域的代表实践是给 LLM 配上化学工具库（ChemCrow 一系）乃至让它自主规划并执行化学实验。这一页的能力上限很高，可靠性上限很低——幻觉与错误传播是贯穿始终的主题。

数学形式

这一页没有标准损失函数——LLM 智能体的"数学"更多是策略与接口的形式化：

工具增强策略   π(a_t | s_t) = LLM( prompt(s_t) )        s_t：对话历史 + 观察记录
ReAct 轨迹     s_t = s_{t−1} ⊕ (思考, 行动(工具, 参数), 观察)   循环至终止符
多智能体       角色各自持有工具子集与系统提示，输出互为输入（分工/互查）
失败链         幻觉 → 工具误用 → 错误传播 → 多智能体互相确认错误（过度自信收敛）

与 01 页的强化学习对比着看很有意思：REINVENT 的"策略"输出的是字符，奖励来自打分器；LLM 智能体的"策略"输出的是工具调用，"奖励"来自任务是否完成——两者的评测都极易被表面信号糊弄。

优点、局限与常见陷阱

  • 优点：把离散的专业工具串成自然语言工作流，集成成本骤降；能读文献与实验记录，补充"数字之外的知识"；多步任务的自动化成为可能。
  • 局限：幻觉——LLM 会编造反应、文献、数字，而化学任务对错误几乎零容忍；工具链错误传播——上游一个错误参数，下游全链作废；评测困难——没有统一基准，"演示成功"不等于"系统可靠"；安全——自主实验能力直接对应危险物质风险。
  • 常见陷阱一：把演示当验证——一段精彩的演示视频/案例不构成系统可靠性的证据，要看失败率统计。
  • 常见陷阱二：让 LLM 直接"输出分子"替代专业生成模型——字符串层面的化学知识不足以保证有效性，专业模型 + LLM 调度才是合理分工。
  • 常见陷阱三：多智能体互相检查变成互相背书——没有独立验证源的互查只会放大错误。
  • 常见陷阱四：忽略工具输出的不确定性——预测器给出的分数没有误差条时，智能体的"自信"毫无依据。
