评测体系与常见陷阱：数字好看不等于分子好用

生成模型论文里的表格越来越漂亮，但"有效性 100%"可能是表示法的功劳，"新颖性 99%"可能是没查训练集，"对接分数创新高"可能是物理上站不住的假结合。这一页讲怎么读这些数字。

核心思想

评测是一个逐级收窄的漏斗：先生成一大批候选，然后依次检查有效性（语法与化学都合法）、唯一性与新颖性（去重、与训练集保持距离）、多样性与分布匹配（性质直方图、分布距离）、目标性质（基准任务或预测器打分）、可合成性（分数或逆合成规划），最末端是前瞻性实验验证——最贵、最慢、也最稀缺。每一级都有对应的基准与工具：GuacaMol 与 MOSES 统一了分布级与目标级指标；指纹工具（ECFP 一系）承担相似性与近邻检查；PoseBusters 一类的物理合理性检查专治"分数虚高"；SELFIES 从表示层面消灭无效字符串。读懂一张评测表的关键问题只有一个：每一级漏斗的口径是什么、有没有被动手脚。

数学形式

有效性     validity = 有效生成数 / 生成总数
唯一性     uniqueness = 去重后数目 / 生成总数
新颖性     novelty = 与训练集指纹相似度均低于阈值的比例
多样性     采样内两两相似度分布的散度（并与训练集的内部多样性对照）
分布级     性质直方图 KL 散度；Fréchet 距离族：
           ‖ μ_r − μ_g ‖² + Tr( Σ_r + Σ_g − 2 (Σ_r Σ_g)^{1/2} )
目标导向   GuacaMol 类基准（发现/优化/中介多任务）；MOSES 的统一 splits 与指标
物理合理性 PoseBusters：键长键角、原子碰撞、立体化学等合理性清单
可合成性   SAscore / SCScore 过滤 + 逆合成可解性（见 09 页）

读表规则：先看每级漏斗的分母（从多少条开始算），再看阈值（新颖性的相似度阈值、有效性的判定器），最后看数据划分（scaffold split 还是 random split）。三者任一不透明，数字就不能跨论文比较。

优点、局限与常见陷阱

  • 这套体系的优点：指标分层清楚，工具开源易得；GuacaMol/MOSES 之后"横向比较"第一次有了共同语言；物理合理性检查把"虚高分"挡在门外。
  • 局限：指标可被优化（模型会顺着你测什么就学什么）；分布级指标对"少数极好分子"不敏感——平均值好看可能掩盖没有候选的事实；基准数据集本身小且有偏（药物样小分子为主）。
  • 常见陷阱一：刷分——在基准上过度调参后报最优跑，等于把测试集用成了训练集。
  • 常见陷阱二：口径漂移——不同论文的 novelty 阈值、validity 判定器、scaffold 划分不同，直接比较毫无意义。
  • 常见陷阱三：只报单点数字不报分布——多样性与尾部质量（最好的那些分子有多好）比均值重要。
  • 常见陷阱四：忽视"活性悬崖"——结构近邻之间活性可能天差地别，指纹相似度高不代表性质可迁移。
  • 常见陷阱五：把对接/预测器分数当真值——预测器本身有误差，用它当"目标命中"的裁判会产生循环验证。
